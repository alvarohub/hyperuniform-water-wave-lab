Model, conventions, and limitations
  • Patterns: a random point set is optimized by minimizing Σ0<|q|≤K|Σjexp(iq·rj)|², with periodic boundary conditions for pattern generation. The scattering calculation uses the resulting finite patch with open boundaries.
  • Nominal cutoff: K = √(16πρχ), and suppressed single scattering is expected for 2k ≤ K. A finite patch, discrete constraints, incomplete optimization, and higher-order scattering prevent this from being an exact on/off switch.
  • Fields: φ(r) = φinc(r) + Σ G(r−rj)bj, with (t⁻¹I−G)b = φinc. G(r) = (i/4)H₀⁽¹⁾(kr)exp(−βr). The exponential loss factor is phenomenological.
  • Point-scatterer response: t = 4u/(1−iu), with u = coupling × [k/(1 cm⁻¹)]. This is an illustrative isotropic response, not a fitted PMMA-cylinder response. The immediate neighborhood of each point is masked.
  • Current: J = Im(φ*∇φ), normalized by the incident current k. Streamlines and contours are calculated from this field, not drawn as decorations.
  • Extinction convention: ⟨φ⟩ ∝ exp[−z/(2ℓe)]. Because β attenuates amplitude, 1/ℓe = 1/ℓs + 2β. Consequently the absorption-corrected fitted coefficient is α = 1/ℓe − 2β.
  • The displayed extinction length is a single-pattern, transverse-coherence estimate—not an ensemble-averaged transport measurement. Poor R², non-decaying fits, or negative corrected α indicate that this estimate is not a reliable scattering mean free path.
  • This is a steady-state scalar-wave demonstration, not a transient fluid solver. It does not model cylinder boundary layers, contact-line physics, nonlinear surface waves, or the experimental uncertainty bars.
