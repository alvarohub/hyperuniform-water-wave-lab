# Hyperuniform Water-Wave Lab

Interactive browser simulation of water-wave scattering: a random point pattern
compared with a Fourier-optimized stealthy-hyperuniform (SHU) pattern, using a
coupled-scatterer model.

**Live site:** https://alvarohub.github.io/hyperuniform-water-wave-lab/

Single self-contained HTML file — no build step, no dependencies. The physics
runs in a Web Worker; the page only renders.

Reference: Campaniello, Carminati, Filoche & Fort,
[_Experimentally controlling scattering of water waves in correlated disorder_](https://arxiv.org/abs/2602.07067),
arXiv:2602.07067 (2026).
